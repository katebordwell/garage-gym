# Garage Gym

A family workout planner built around our garage gym kit, made at hack day with Claude.

**See it live:** https://katebordwell.github.io/garage-gym/

- Plan each person's week with real times, including runs, rides and classes
- Build garage sessions from short follow-along clips that match the kit we own
- Spot kit clashes and train together when sessions overlap
- Prioritise what to buy next with family votes
- Earn points for finished sessions: the winner picks Saturday dinner and every point fills the family kit jar

Everything is one `index.html` file. Data is saved in your own browser only.
